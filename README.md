# 基于 FPGA 的无人机声学追踪系统

**Acoustic Drone Tracking** · 四元麦克风阵列 · GCC-PHAT · XC7A100T · 端侧实时声学测向

一套在单片 XC7A100T FPGA 内完成「采集 → 测向 → 显示 / 云台指向」全闭环的低成本、被动、实时声学追踪系统。四只 I2S 数字麦克风组成对臂 38.6 cm 的共面十字阵，10 kHz / 24 bit 同步采样；50 MHz 单时钟、帧级流水，单帧端到端约 7.2k 拍（144 µs，仅占 25.6 ms 帧预算的 0.56%）。系统被动工作、不依赖光照，可作为雷达与光电的低成本补充节点。

## 项目简介

针对低空无人机监测、安防与机器人听觉对低成本、被动、实时测向的需求，本系统以四只 INMP441 数字麦克风构成共面十字阵列，在单片 Artix-7 FPGA 内完成 900 Hz 高通、帧级 AGC、Hanning 加窗、四路并行 256 点 FFT、学习型频点掩码、六对 GCC-PHAT、1024 点 IFFT、抛物线插值、128 帧六对联合投票与角度解算，并直接驱动 8 位数码管与 SG90 二维云台。整机无需 PC、GPU 或专用采集卡，端侧实时输出六组时延、方位角与俯仰角。

## 应用领域

- **低空安防与要地监测**：园区、场馆、机场净空区、变电站与油库等场景，声学探测不发射电磁波、不受光照与烟尘影响，给出方位/俯仰角可直接带动云台摄像机对准可疑方向。
- **反无人机演示与验证**：输出标准串口帧（6 组时延 + 方位角/俯仰角），可直接接入上位机或反制设备，作为多手段融合测试的声学分系统。
- **科研与教学**：逐帧时延与角度输出，可作为 GCC-PHAT、阵列信号处理、FPGA 定点设计的实验平台。
- **低成本批量部署**：核心器件仅 XC7A100T 开发板、四只 INMP441、两只 SG90，适合多点组网与快速验证。

## 核心特性与创新点

- **端侧一体化闭环**：采集、加窗、FFT、测向、显示与云台控制全部在单片 FPGA 内完成；50 MHz 单时钟、帧级流水，单帧端到端约 7.2k 拍，帧预算余量超过 170 倍。
- **四路并行前端**：四颗 256 点 FFT 同拍并行变换，帧缓存读口由分时的 3072 拍降到 256 拍，频域缓存由 1024 深降到 129 深（只保留 0~128 单边频点）。
- **双段流水 CORDIC 归一化**：同时完成 PHAT 归一化与相位提取，省去除法器与开方器；模长小于 100 LSB 的频点直接清零，等效给分母加下限。
- **六对共享 IFFT**：六对互谱分时送入一颗 1024 点 IFFT，补零 4 倍内插后由抛物线插值把时延分辨力细化到 1/1024 采样点。
- **多级抗噪与稳健输出**：900 Hz 高通、帧级 AGC、学习型频点掩码、逐对有效性判据、128 帧六对联合投票逐级筛选；投票建立前用 5 帧中值回退，保证上电即有粗角度。
- **参数化配置**：位宽、点数、目标频段、AGC 档位、舵机行程集中在统一参数包中定义，模块间只通过「帧有效脉冲 + 帧号 + 频域突发」同步，无跨时钟域、无反压等待。

## 系统架构

### 总体数据流

```text
I2S 采集 → 900 Hz 高通 → 帧级 AGC → Hanning 加窗 → 4× 并行 256 点 FFT
        → 129 点单边谱 → 学习型频点掩码 → 6 对 GCC-PHAT + 双段 CORDIC 归一化
        → 1024 点 IFFT → 抛物线峰值插值 → 128 帧六对联合投票
        → 方位/俯仰解算 → UART / 8 位数码管 / 双轴云台 PWM
```

整条链路在 50 MHz 单时钟域按帧推进：采集分包写满 256 点后给出帧有效脉冲与帧号；预处理分包从乒乓帧缓存四路并行读出整帧，加窗后送四颗 FFT，只保留 129 个单边频点并做频点掩码；测向分包逐对计算互谱、用 CORDIC 完成 PHAT 归一化，补零到 1024 点做 IFFT，抛物线插值出六对时延，再经 128 帧投票解算成二维角度。三个分包之间没有跨时钟域、没有反压等待，单帧处理约 7.2k 拍，而帧间隔为 1.28M 拍（25.6 ms）。

### 硬件组成

硬件由四部分组成：四元麦克风阵列、FPGA 核心板、显示与云台外设、独立电源。

- **主控**：XC7A100T-FGG484-2（Artix-7，约 10.1 万逻辑单元、240 个 DSP48E1、135 个 36 Kb BRAM），板载 50 MHz 有源晶振、复位按键、USB-TTL 与 QSPI Flash。
- **阵列**：中央八角集线板 + 四条延长板 + 四只 INMP441 麦克风小板拼装成十字四臂；四只麦克风共面、振膜朝同一侧，拾音孔距中心约 19.3 cm（对臂实测 38.6 cm）。四麦共用同一 BCLK/LRCK，四路 SD 走线等长，硬件上严格同步。
- **显示**：板载两片 74HC595 级联驱动 8 位七段数码管，16 bit 串行帧为 `{DP, seg[6:0], sel[7:0]}`，位扫描 1 kHz、整屏 125 Hz。
- **云台**：两只 SG90 正交组成二维云台，两路 50 Hz PWM（0.5~2.5 ms 对应 0°~180°），俯仰机械限位 10°~180°，云台上安装摄像头；舵机峰值电流可达 1 A/只，使用外部 5 V 独立供电并与 FPGA 共地。

## 算法要点

### GCC-PHAT 与双段 CORDIC 归一化

设第 a、b 只麦克风的频谱为 `X_a(k)`、`X_b(k)`，加权互谱与时延估计为：

```text
R_ab(τ) = Σ_k [X_a(k)·X_b*(k) / |X_a(k)·X_b*(k)|] · e^{j2πkτ/N}
τ_ab    = argmax_τ R_ab(τ)
```

分母完成 PHAT 归一化，使互谱只剩相位信息，对幅度起伏与混响不敏感。本设计用双段流水 CORDIC 实现该除法：段 1（20 级 vectoring）把向量旋到 +x 轴得到模长与相位，段 2（20 级 rotation）从 +x 轴旋转该相位，输出模长恒为 1 的单位向量，省去除法器；实部为负时先预旋转 180°，使 vectoring 的收敛域覆盖全相位；模长小于 100 LSB 的频点直接清零，等效给分母加下限。

### 六对共享 IFFT 与抛物线峰值插值

`pair_scheduler` 逐对执行「复乘 → CORDIC 归一化 → 按掩码写 PHAT 缓存 → 构造 1024 点 IFFT 输入」：0~128 直读 PHAT，129~895 补零，896~1023 取共轭对称点，补零到 1024 点等效 4 倍时域内插。峰值检测只在物理时延窗 ±45 点（对应 ±11.25 采样点，即对臂 38.6 cm 的物理上限）内找同相分量最大值，峰落在帧首/帧尾时用环形邻点补全，消除 0.5 点系统性偏移：

```text
δ = 0.5·(y₋₁ − y₊₁) / (y₋₁ − 2y₀ + y₊₁)
```

其中 `y₋₁、y₀、y₊₁` 为峰值与左右邻点幅值，δ 以 1/256 采样点为单位；输出 Q10 时延。若整对没有频点过门，`tdoa_used = 0`，标记本对无信息、不参与投票。

### 128 帧六对联合投票

单帧时延的抖动接近均匀分布，短窗中值压不住；但真实方向在六对时延上同时满足远场恒等式，噪声与栅瓣只满足其中一两对。因此对每对保留 23 档（1 采样点/档，−11..+11）直方图与 128 帧环形缓冲，每帧「减最旧、加最新」精确滑窗；每 4 帧枚举 τ01、τ23 共 23×23 个候选，其余四对由远场恒等式推出，取六对计数之和最大者，再用相邻档抛物线插值到 1/8 采样点。置信判据为 `best_score > filled`（峰值约为背景的 1.9 倍），不满足时 `direction_valid = 0`。

首窗攒满 128 帧才置 `vote_ready`（39.06 帧/s 下约 3.28 s）。在此之前不输出投票值，先直接输出单帧结果，4 帧后切换为 5 帧中值，保证上电即有粗角度、又不把未收敛的直方图当成稳定结果。投票建立后对投票时延再做 3 点中值，进一步压住偶发跳档；本版没有提前锁定与快速重锁，换向完全依赖 128 帧滑窗自然滑出旧票，响应约 1.6 s。

### 角度解算

以投票后的 τ01、τ23 按远场平面波关系换算方向余弦，再解出方位角与俯仰角：

```text
cos α = c·τ01/(2d)，  cos β = c·τ23/(2d)，  cos γ = √(1 − cos²α − cos²β)
φ     = atan2(cos β, cos α)，  θ = atan2(cos γ, √(cos²α + cos²β))
```

工程中把 `c/(2d·fs)` 合并为常数 `COS_K = 46588`（`>>>6`，`K_eff = 727.9375`，对应实测对臂 38.6 cm），τ 以 Q10 采样点代入，`ca/cb` 为 Q23；`TAU_MAX = 11523` 对应 `|cos| ≤ 1` 的物理上限。Σcos² 判决规则：`> 1.25` 整帧拒判；`1~1.25` 时俯仰角饱和到 0°、方位角仍输出（用一致性换可用性）；`(τ01, τ23) = (0,0)` 判为声源正上方，θ = 90°。φ、θ 复用 CORDIC 角度输出（Q26），再换算为 0.1° 整数，四舍五入采用 round-half-away-from-zero，负角先取绝对值再补符号。

## 通信协议（UART）

系统每帧通过 UART 输出 91 字节 ASCII 帧，包含六组 TDOA、方位/俯仰角、有效位与异或校验和。正常输出示例（帧号 0042，方位 +45.0°，俯仰 +51.8°，V = 1）：

```text
$GCCP,0042,T01:+005,T02:+000,T03:+005,T12:-005,T13:+005,T23:+005,A:+045.0,E:+051.8,V:1*46
```

| 字段 | 字节 | 说明 |
| --- | --- | --- |
| `$GCCP,` | 6 | 帧头 |
| `FFFF,` | 5 | 4 位帧号 0000~9999 + 逗号 |
| `T01:±nnn,` … `T23:±nnn,` | 54 | 6 组配对，每组 9 字节；带符号，数值为 τ 绝对值右移 10 位的整数采样点 |
| `A:±ddd.d,` | 9 | 方位角，符号 + 3 位整数 + 1 位小数 |
| `E:±ddd.d,` | 9 | 俯仰角 |
| `V:n` | 3 | 有效位 0/1 |
| `*hh` | 3 | 前 86 字节的异或校验和（2 位十六进制） |
| `CR LF` | 2 | 0x0D 0x0A |

十进制位用逐位减法提取，全程无除法；小数位复用整数位拆完的余数。UART 忙时到达的新 `frame_valid` 整帧丢弃，避免拼出校验和自洽但内容错乱的拼接帧；学习期与无效解也照常发帧（`V:0`），让上位机可以区分「链路故障」与「本帧无效」。115200 8N1 下每帧约 7.9 ms，小于 25.6 ms 帧间隔，因此每帧都能完整发送。

本地显示按「负号 + 方位角 3 位 + 熄灭 1 位 + 俯仰角 3 位」布局，例如方位 −45°、俯仰 52° 显示为 `-045 052`；上电后第一帧有效结果之前整屏显示 `-`。云台把角度换算成两路 50 Hz PWM：`pulse = 25,000 + angle_01deg × 100,000 / 1800` 拍；方位角为负时整机翻转（`pan = az + 180°`、`tilt = 180° − el`），非负时 `pan = az`、`tilt = el`；pan 钳位 0~180°，tilt 钳位 10~180°，新脉宽在 PWM 周期边界统一装入，避免窄毛刺。

## 快速开始

1. **硬件准备**：XC7A100T-FGG484-2 开发板、4 只 INMP441 模块、十字阵列 PCB、2 只 SG90 舵机及外部 5 V 电源（≥1 A，必须与 FPGA 共地）；50 MHz 晶振与复位按键板载。
2. **综合 / 烧录**：用 Vivado 2018.3 打开 `GCC-PHAT/GCC-PHAT.xpr` 自行综合实现，或直接将 `board/top_gcc_phat.bit` 烧录至 FPGA。
3. **连接串口**：将开发板 UART TX（M15）接 USB-TTL，串口参数 115200 8N1。
4. **观察结果**：8 位数码管显示方位/俯仰角，双轴云台自动指向声源方向。
5. **记录数据**：`pip install pyserial` 后运行 `python board/uart_monitor.py -p COM3 -b 115200 -o gccp_log.txt`，可加 `--hex` 或 `--timestamp` 记录原始帧。
6. **上电行为**：首帧即有粗角度（单帧 → 4 帧后 5 帧中值），约 3.28 s 后进入 128 帧投票稳定输出；纯风声等无效场景输出 `V:0`。

## 验证与实测

- **定点模型**：先用 Python 建立浮点与定点参考模型，确定 Q 格式与误差预算，再逐点比对 RTL；设计流程为「算法建模 → 定点设计 → RTL 实现 → 仿真回归 → 综合实现 → 上板标定」，迭代两轮后定版。
- **仿真回归**：`sim/` 下 19 个定向 TB 覆盖 I2S 接收、AGC、四路 FFT 链、CORDIC、PHAT 顶层、TDOA 解算与投票、UART、数码管与舵机等关键链路；全链路仿真远场/近场时延偏差 ≤ 16/1024 采样点。
- **真实录音回放**：`data/` 下 5 个真实录音文件（4 通道）定点回放，5~50 m 内置信度持续为 1；纯风声场景 143/144 帧整帧跳过，不输出方向。
- **角度误差预算**（静态链路逐项估算，均方根合成 < 0.07°）：Q10 时延量化约 0.020°；`COS_K` 与实测臂长舍入约 0.001°；开方与归一化约 0.001°；CORDIC 角度与 Q26 截断合计约 0.0002°；0.1° 输出四舍五入 ±0.05°（主导项）。
- **资源与时序**：见上文「资源与时序」表，DRC 0 Error，50 MHz 下 WNS +2.770 ns、WHS +0.015 ns。

## 已知限制

- **共面阵镜像模糊**：四麦共面，第三个方向余弦的符号无法确定，存在镜像解；需在阵列平面外增加第五只麦克风定符号，才能从「方向」升级为三维坐标。
- **输出与响应**：角度输出 0.1° 量化；128 帧投票首次稳定输出约 3.28 s，换向约 1.6 s，无提前锁定/快速重锁机制。
- **标定边界**：外场作用距离与绝对角度精度尚未用标准源标定，表中 5~50 m 与误差为仿真、录音回放及理论预算结果，不代表外场实测。
- **机械约束**：舵机需外部 5 V 独立供电并共地；俯仰最低只能到 10°（机械限位），程序钳位需与之一致，避免憋舵打齿。
- **资源余量**：Slice 76.66%、DSP 80.0%，继续扩展（如 48 kHz / 1024 点、多声源）前需重新评估布局与 DSP 预算。
