# GCC-PHAT 技术对话索引

本目录保存从项目开发会话中筛选出的技术讨论，供复现、交接与问题追溯使用。
原始会话记录、工具调用日志和未筛选语料不随仓库分发。

## 文件

| 文件 | 内容 |
|---|---|
| `技术对话.md` | 88 组技术问答，按五个阶段编排；用户侧保留原始提问，助手侧取当轮摘要的首条响应与最相关一条 |

## 筛选口径

保留与工程实现直接相关的内容：

- RTL / SystemVerilog、Vivado 综合、实现、时序与资源
- GCC-PHAT、FFT/IFFT、CORDIC、TDOA、掩膜、投票、AGC 等算法链路
- 麦克风阵列几何、半径与间距、真实录音回放、远场修正
- 板级调试、串口与数码管、SG90 云台、STM32 链路
- 引脚约束、bit/bin 产物、版本回退与重建

只保留提问与助手技术回复成对出现的内容；缺少回复的片段不单独收录。

删除的内容：

- 寒暄、进度询问、任务通知、中断与上下文压缩续写
- 与工程实现无关的工具选型、文档排版、仓库管理
- 本地绝对路径、外链与敏感字符串（统一替换为占位符）
